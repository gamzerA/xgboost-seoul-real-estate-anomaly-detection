# Data

이 프로젝트는 국토교통부 실거래가 공개시스템에서 내려받은 서울시 아파트 매매 CSV를 사용합니다.

## 필요한 파일

`data/raw/` 아래에 다음 이름으로 파일을 배치합니다.

```text
data/raw/
├── 서울실거래가_2022.csv
├── 서울실거래가_2023.csv
├── 서울실거래가_2024.csv
└── 서울실거래가_2025.csv
```

원자료는 용량과 재배포 조건을 고려해 Git 저장소에 포함하지 않습니다.

- 출처: [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/)
- 대상: 서울특별시 아파트 매매
- 기간: 2022–2025년
- 분석에 사용된 전처리 후 거래 수: 189,864건

CSV의 컬럼명과 상단 설명 행은 내려받은 시점에 따라 달라질 수 있습니다. 현재 코드는 `cp949` 인코딩과 상단 15개 설명 행이 있는 형식을 우선 처리하고, 설명 행이 없는 파일도 다시 시도합니다.
